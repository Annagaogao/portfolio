# images/ — 网站用图

每个文件夹对应网站的一个区块或一个项目，文件夹里的 README 写了要放哪几张、叫什么名字。

```
00-hero/            首屏主视觉
01-flock-web/       FLock.io 官网 + chat.flock.io
02-andlight/        和光科技 品牌系统
03-gto-outdoor/     壮游户外 GTO
04-ultrax/          UltraX
05-fmgo/            FMGO 品牌物料
06-flock-posters/   FLock 社媒海报
07-qwen-hackathon/  Qwen × Skyst Hackathon
08-fomo/            FOMO 产品识别
09-services/        服务区四张卡的图
10-method/          方法区三张高卡的图
11-about/           工作照
12-brand/           个人 Logo、二维码
```

规格：网站展示 JPG 80%、长边 2400px；Logo / 透明图 PNG；头像正方形 1200×1200。
文件名按各文件夹 README 里写的来，网站代码引用的就是这些名字。
